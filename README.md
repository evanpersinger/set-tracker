# Set Tracker

A rest timer and set tracker for the gym, built for phone use. Tap a set button to mark it done and start the rest countdown.

Live site: https://evanpersinger.github.io/Set-Tracker/

## Modes

- **Option 1:** 2 min rest, 6 sets
- **Option 2:** 3 min rest, pick 2, 3, or 4 sets

The timer compares against the real clock, so it stays accurate if the tab is backgrounded or the phone locks.

## Run it

Open `index.html` in a browser. Plain HTML, CSS, and JS in one file, no build step.
